V Vyora User Flows

Fourteen core journeys

Every flow is local-first: steps complete on-device and sync in the background. Diamonds are decisions; green is a start, dark is an end.

Start Step Decision End
01

Onboarding

Registration

Start → Enter mobile / email → Verify OTP → Set password → Account created

Login

Start → Enter credentials → ◇ Valid? →
YesLoad local data→Dashboard
NoError → retry / reset

Company setup

Start → Name & GSTIN → Address & contact → Upload logo → Generate encryption key → Business selection

Business selection

Start → Choose business type → Metadata generates fields → Preview workspace → Confirm → Dashboard
02

Transactions

First invoice

New invoice → Add customer → Add items (dynamic fields) → Auto GST → Save (local) → ◇ Online? →
YesSync + WhatsApp send
NoQueued — syncs later

Purchase workflow

New PO → Select supplier → Add items → Send PO → Receive goods (GRN) → Purchase bill → Stock updated

Return workflow

Open invoice / bill → Select return items → Choose reason → Credit / debit note → Stock adjusted → Refund / adjust

Payment workflow

Open invoice → Record payment → ◇ Full or partial? →
FullMarked paid
PartialBalance due tracked
→ Receipt + ledger

Stock management

Inventory → ◇ Trigger →
AlertLow-stock / expiry
ManualAdjust count
→ Reorder / update batches → Synced
03

Data & account

Backup

Settings → Backup → Encrypt snapshot → ◇ Destination →
LocalDownload .vyora file
CloudEncrypted to Storage
→ Done

Restore

Settings → Restore → Select backup → ◇ Valid key? →
YesDecrypt & merge→Restored
NoError — key required

Subscription

Plans → Choose seats (1–unlimited) → Payment → Activate → Seats provisioned
04

Intelligence

AI assistant

Open Copilot → Type / speak request → Interpret intent → ◇ Action? →
CreateDraft doc → review → confirm
AnswerReport / insight inline

OCR capture

Upload PO / bill photo → OCR extract → AI maps fields → Review & edit → Invoice / expense created
